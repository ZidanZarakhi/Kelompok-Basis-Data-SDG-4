
# Modul 11 – Perkembangan DBMS dan Lingkup Penerapan Basis Data

## Deskripsi
Repository ini berisi dokumentasi dan implementasi tugas Modul 11 mata kuliah Basis Data dengan studi kasus **Simpul (Sistem Informasi Pembelajaran)**.

Sistem Simpul dirancang untuk mengelola data pembelajaran, seperti pengguna, sekolah, kelas, siswa, mata pelajaran, kuis, soal, materi, dan nilai.

## Teknologi
- **MariaDB 10.4.28** – Database Management System.
- **SQL** – Pengelolaan dan manipulasi basis data.
- **JSON** – Penyimpanan data dengan struktur fleksibel.
- **Git & GitHub** – Version control dan dokumentasi proyek.

## Isi Repository
- Analisis perkembangan dan perbandingan DBMS.
- Implementasi basis data Simpul.
- Pengujian fitur JSON dan operasi CRUD.
- Identifikasi fasilitas pengelolaan transaksi.
- Diagram pemodelan objek.
- Analisis kebutuhan dan lingkup penerapan basis data.

## DBMS yang Digunakan
MariaDB dipilih karena mendukung basis data relasional, transaksi menggunakan InnoDB, integritas referensial, serta fungsi JSON untuk mengelola data semi-terstruktur.
